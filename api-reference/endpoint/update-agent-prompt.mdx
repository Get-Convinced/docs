---
title: 'Update agent prompt'
description: 'Persist the system prompt, first message, or both in Convinced.'
---

```http
PATCH /api/org/{orgSlug}/sdk-agents/{agentId}/prompt
```

Use an authenticated Convinced administrator session on the Convinced application origin, or a narrow same-origin management proxy that authenticates and authorizes the administrator before forwarding the request server-side. The proxy must not accept visitor credentials or forward arbitrary paths.

```ts
const current = await admin.getPrompt()

const saved = await admin.updatePrompt({
  systemPrompt: nextSystemPrompt,
  firstMessage: nextFirstMessage,
  expectedRevision: current.revision,
})
```

At least one editable field is required. `systemPrompt` must be non-empty and at most 100,000 UTF-8 bytes. `firstMessage` may be empty and is limited to 10,000 UTF-8 bytes. The encoded body is limited to 700,000 bytes.

Omitted fields are preserved. The server updates the current live Convinced prompt version, reads it back, and returns the same shape as GET. It does not update any third-party provider.

| Status | Meaning |
| --- | --- |
| `400` | Invalid JSON, fields, or revision shape |
| `403` | Admin or same-origin requirement failed |
| `404` | Deployment or live prompt was not found |
| `409 prompt_conflict` | The prompt changed; reload before saving |
| `413` | Request body is too large |
| `502 prompt_verification_failed` | The saved value could not be verified |
