---
title: 'Get agent prompt'
description: 'Read the live Convinced prompt for an authorized AgentDeployment.'
---

```http
GET /api/org/{orgSlug}/sdk-agents/{agentId}/prompt
```

Requires an authenticated Convinced organization `ADMIN` session, either on the Convinced application origin or through an approved same-origin management proxy that authenticates and authorizes the administrator server-side. `agentId` is the Convinced `AgentDeployment` ID. A public widget token, Campaign API key, or provider identifier is not accepted.

```ts
const prompt = await admin.getPrompt()
```

```json
{
  "source": "convinced",
  "agentId": "adpl_public_example",
  "promptVersionId": "prv_live_example",
  "systemPrompt": "Help visitors understand this website.",
  "firstMessage": "What are you trying to improve today?",
  "revision": "<sha256>",
  "updatedAt": "2026-09-22T08:30:00.000Z"
}
```

Responses use `Cache-Control: private, no-store`. Common errors are `403 admin_required`, `404 agent_not_found`, and `404 prompt_not_found`.

Use the returned `revision` when updating the prompt.
