---
title: 'Upsert campaign'
openapi: 'POST /api/campaigns'
---

Create or update a campaign using a partner key on the [public Campaign API origin](/api-reference/introduction#campaign-base-url).

## Request

| Field | Required | Behavior |
| --- | --- | --- |
| `name` | Yes | Non-empty string after trimming |
| `slug` | No | Derived from name when omitted or blank; normalized to lowercase, hyphens and digits, then truncated to 64 characters |
| `description` | No | Non-empty trimmed string updates the description; omitted or blank values preserve it on an existing campaign |

Normalization replaces invalid characters with hyphens and collapses repeated hyphens. It does not reject every uppercase letter or space. Save the returned slug, which can differ from your input. An empty normalized identifier is rejected.

```bash
curl --fail-with-body "$CONVINCED_API_BASE/api/campaigns" \
  -H "Authorization: Bearer $CONVINCED_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"Logistics outreach","slug":"logistics-outreach","description":"Account outreach"}'
```

## Response

```json
{
  "campaign": {
    "id": "11111111-1111-4111-8111-111111111111",
    "name": "Logistics outreach",
    "slug": "logistics-outreach",
    "description": "Account outreach",
    "status": "active",
    "created_at": "2026-09-14T10:00:00.000Z",
    "updated_at": "2026-09-14T10:00:00.000Z"
  }
}
```

Campaign timestamps use snake_case. Repeating the same organization and slug preserves the ID and creation time. The API creates campaigns as `active`; it does not update their status through this endpoint. Only active campaigns are ready for personalized widget use.

## Errors

- `400`: missing name or an empty normalized slug.
- `401` / `403`: credential or scope problem.
- `413`: body larger than 1 MiB.
- `429`: shared partner-key limit reached.
- `500`: operation failed.
