For a website SDK implementation, start with [SDK overview](/guides/widget-sdk/overview). This quickstart adds optional account personalization through the Campaign API.

## Prerequisites

- A Convinced organization and an enabled widget deployment.
- A partner API key from [Settings → API Keys](/guides/getting-started/api-keys).
- A terminal with `curl` and `jq`, or a server-side integration.

```bash
export CONVINCED_API_BASE="https://convinced-kb-mcp-production.up.railway.app"
export CONVINCED_API_KEY="<your-partner-api-key>"
```

Keep the key outside the browser. The public Campaign API is a separate service from `app.getconvinced.ai`.

## Create a campaign

```bash
curl --fail-with-body "$CONVINCED_API_BASE/api/campaigns" \
  -H "Authorization: Bearer $CONVINCED_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"Logistics outreach","slug":"logistics-outreach"}'
```

Save the returned `campaign.slug`. Repeating a slug updates that campaign. The campaign response uses `created_at` and `updated_at`; target responses use camelCase timestamps.

## Save a target

Use structured intel for a synchronous first integration:

```bash
curl --fail-with-body "$CONVINCED_API_BASE/api/campaigns/logistics-outreach/targets" \
  -H "Authorization: Bearer $CONVINCED_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "companyName":"Acme Logistics",
    "token":"acme-logistics",
    "enrich":false,
    "intel":{
      "companySummary":"A logistics company coordinating last-mile deliveries.",
      "painPoints":["Dispatchers spend too much time updating delivery plans."]
    }
  }'
```

The response contains `widgetToken`, `widgetQuery`, and `target.enrichmentStatus: "skipped"`. It does not contain `widgetReady`; obtain that from GET below.

<Warning>
  A token identifies one target across the entire organization. Reusing it under a different campaign moves the existing target into that campaign and replaces its data. Use a distinct token for each distinct account record.
</Warning>

## Check readiness

```bash
curl --fail-with-body "$CONVINCED_API_BASE/api/campaigns/logistics-outreach/targets/acme-logistics" \
  -H "Authorization: Bearer $CONVINCED_API_KEY" | jq '.target.widgetReady'
```

Proceed when `widgetReady` is true. It combines active campaign status, stored intel, and a `done` or `skipped` enrichment state.

If you only have research notes, use [auto-enrich](/guides/campaigns/auto-enrich): send `rawResearch`, optional `links`, and `enrich: true`; then poll GET with a bounded timeout. Enrichment is asynchronous and its completion time varies.

## Open the personalized widget

For a hosted widget:

```text
https://app.getconvinced.ai/widget/v2/<your-org-slug>?c=acme-logistics
```

To embed the managed widget on your site:

```html
<script
  src="https://app.getconvinced.ai/widget/loader.js"
  data-org="<your-org-slug>"
  data-c="acme-logistics"
  async
></script>
```

A campaign token selects account context; it does not grant knowledge API access or let a visitor edit your agent. Treat campaign context as information that anyone with a working visitor link may encounter.

Continue with [SDK overview](/guides/widget-sdk/overview) for a custom page integration, [widget embedding](/guides/campaigns/widget-embedding) for loader options, or the [Campaign API reference](/api-reference/introduction).
