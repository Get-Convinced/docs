Build a Convinced Widget SDK 0.1.5 integration for this website.

Install and pin @convinced/widget-sdk@0.1.5 and commit the lockfile. Use the existing application framework. Do not depend on private Convinced repositories or invent credentials, deployment IDs, routes, or product settings.

Create one ClientToolRegistry and one ConvincedClient({ orgSlug, agentId, tools, authorizeToolCall }). agentId is the public Convinced AgentDeployment ID. Keep every OpenAI key, provider identifier, management credential, and server secret out of browser code.

Use client.sendMessage() for every typed turn. Keep one shared Convinced conversation history; gpt-6-luna handles typed and grounded requests. If speech is required, create one reusable controller with client.createLiveController(), start it only from a visitor gesture, and let gpt-live-1 handle greetings and conversational clarifications directly. Delegate grounded organization, page, slide, and tool requests to gpt-6-luna. Completed Live-native user/assistant pairs join client.state.messages and provide context to typed and delegated Luna requests; do not force every utterance through client.sendMessage(). Typed input while Live is connected must be spoken. live.end() must leave chat active. Chat-only use must create no Live session.

Use live.on() or live.subscribe() and retain their unsubscribe functions. Do not call once() or off() on the Live controller. Render only text, slide, and video message content. Render shared history from client state updates: completed native pairs notify state subscribers without duplicate client message events. Live onMessage/message/message_delta callbacks remain available for captions; do not replay captions as new chat turns. The default client.endSession() transcript includes completed pairs, not every fragment; do not assume reload/reconnect recovery. Implement forms through host UI and registered tools.

Register each browser capability once with handler, an object JSON schema, effect, consent, timeout, and a bounded result that reports the observed outcome. Use the same registry for typed and spoken turns. Preserve the opaque signed pause/execute/resume flow: the browser validates the local call, schema, bounds, and host policy; the Convinced backend verifies the signature and exact organization/session/turn/call binding before resuming gpt-6-luna.

For WebMCP publishing, call client.publishToolsToWebMcp(), await publisher?.ready, and dispose it on teardown. If the Convinced agent must consume tools registered by another same-origin component, feature-detect with getWebMcpModelContext(), createWebMcpBridge({ modelContext, origin, authorize, argumentEncoding }), register bridge.tools, and dispose the bridge. Never retry a mutation with a different argument encoding.

Choose the UI deliberately. For a headless integration, the host owns layout, theme, slide behavior, forms, and responsive states. For the optional managed renderer, use mountConvincedWidget({ client, voice: live }).

Persistent systemPrompt and firstMessage edits belong in ConvincedAgentAdmin on an authenticated same-origin Convinced admin surface or approved same-origin management proxy. The API updates Convinced only. Preserve expectedRevision and reload after a 409 or uncertain network result.

Keep one client owner across SPA route changes, update page context, unregister stale route tools, and end the session from a reliable awaited application action. Do not rely on beforeunload.

Run typecheck, unit tests, and real-browser acceptance. Prove chat-only, voice opt-in, direct Live greetings and clarification, typed and delegated grounded follow-ups that receive the completed native context, completed pairs in the default session-end transcript, interruption, typed input during voice, voice-off chat, tool success and denial, WebMCP fallback, route continuity, slides, host forms, prompt conflict, and explicit session completion. Inspect browser source, requests, storage, and logs for secrets or provider identifiers.

Report exact changed files, commands, results, and anything blocked. Open a reviewable pull request for the website team.
