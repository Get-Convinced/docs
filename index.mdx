## Credentials and API reference

The browser SDK, Campaign/Knowledge APIs, and agent administration use different authentication. A partner API key belongs on your backend; prompt editing requires a Convinced organization ADMIN session. See the [API overview](/api-reference/introduction) before choosing credentials.

For launch checks, use the [implementation checklist](/guides/widget-sdk/client-handoff). For help, contact [Convinced support](mailto:hi@getconvinced.ai).
