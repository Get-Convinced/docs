A campaign token selects account context; the widget's organization selects the tenant. Use the same token with the managed widget or the SDK. For a general website integration, start with [SDK overview](/guides/widget-sdk/overview).

## The widgetReady gate

Before sharing a link, read [GET target status](/api-reference/endpoint/get-target) from your backend and confirm `target.widgetReady === true`. The boolean requires an active campaign, stored intel, and a `done` or `skipped` enrichment state.

```ts
const response = await fetch(
  `${process.env.CONVINCED_API_BASE}/api/campaigns/${encodeURIComponent(slug)}/targets/${encodeURIComponent(token)}`,
  { headers: { Authorization: `Bearer ${process.env.CONVINCED_API_KEY}` } },
)
if (!response.ok) throw new Error(`Target read failed: ${response.status}`)
const { target } = await response.json()
if (!target.widgetReady) throw new Error('Campaign target is not ready')
```

This code runs on your server. The partner API key must never be included in a browser bundle. Upsert responses do not contain `widgetReady`.

## Managed loader

```html
<script
  src="https://app.getconvinced.ai/widget/loader.js"
  data-org="<your-org-slug>"
  async
></script>
```

Send a visitor to `https://your-site.example/demo?c=acme-logistics`. Alternatively, set `data-c="acme-logistics"` to pin a page to one target.

The loader resolves the campaign token in this order:

1. Explicit `data-c`.
2. The page's `?c=` query parameter.
3. A `/for/<token>/` path segment.
4. `?utm_campaign=` as a legacy fallback.

Prefer explicit `c` or `data-c`; a marketing campaign label is not necessarily a valid target token. A resolving personal link (`pid`) takes precedence over campaign personalization on the backend.

### Pretty paths

```text
https://your-site.example/for/acme-logistics/
```

Your website must route that path to the page containing the loader. The loader extracts the token; it does not create pages or configure your router.

### Loader attributes

| Attribute | Meaning |
| --- | --- |
| `data-org` | Required organization slug |
| `data-c` | Explicit campaign target token |
| `data-pid` | Explicit personal-link identifier |
| `data-token` | Public embed credential if required by your widget configuration; never a partner or ElevenLabs key |
| `data-launcher` | Launcher preview override |
| `data-bottom-offset` | Supported CSS offset for launcher placement |
| `data-test="true"` | Request test mode |
| `data-debug="true"` | Request the debug surface |

The deployed loader exposes `openConvinced`, `closeConvinced`, `sendEvent`, and `setIdentity` on `window.Convinced`. It does not currently implement a parent-page host-tool bridge. For website actions, use the direct SDK integration described in [WebMCP website tools](/guides/widget-sdk/webmcp), subject to that guide's runtime limitations.

## Hosted full-page widget

```text
https://app.getconvinced.ai/widget/v2/<your-org-slug>?c=acme-logistics
```

Use this when you do not need a custom landing page. The organization needs an enabled widget configuration. A usable token must belong to that organization.

## SDK integration

Use [Campaign sessions in the SDK](/guides/widget-sdk/campaigns) to pass the token and apply returned session personalization. Initializing the SDK with account data does not automatically rewrite a saved provider agent or guarantee that a custom voice start applies the context.

For additional pages, follow [SDK overview](/guides/widget-sdk/overview) and expose each page's own actions. Campaigns are optional account personalization; WebMCP is the interface for page actions.

## Tracking and attribution

The managed loader forwards `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, and `utm_term` from the parent URL to the hosted widget. Keep your own website analytics for first-party page visits and conversions. Verify the attribution fields your integration actually consumes rather than assuming that every downstream conversion automatically contains these tags.

## Common pitfalls

- A generic session can mean the token is missing, belongs to another organization, has no usable intel, or is in an inactive campaign.
- `data-c` overrides `?c=`. Remove the explicit attribute when one page must serve many targets.
- A campaign token represents an account record, not the identity of whoever opens it. Avoid placing private personal details in public-link context.
- Reusing a token in a different campaign moves the same target record. Use distinct tokens for records that must remain separate.
