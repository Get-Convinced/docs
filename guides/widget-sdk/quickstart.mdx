## 1. Install 0.1.7

<CodeGroup>
```bash npm
npm install @convinced/widget-sdk@0.1.7
```

```bash pnpm
pnpm add @convinced/widget-sdk@0.1.7
```

```bash bun
bun add @convinced/widget-sdk@0.1.7
```
</CodeGroup>

The package is framework-neutral ESM with TypeScript declarations. Its core is headless; `mountConvincedWidget()` is an optional managed renderer.

## 2. Create one tool registry

```ts
import {
  ClientToolRegistry,
  ConvincedClient,
} from '@convinced/widget-sdk'

const tools = new ClientToolRegistry()

tools.register({
  version: 1,
  name: 'host_open_pricing',
  description: 'Open the pricing section on the current website.',
  inputSchema: { type: 'object', properties: {}, additionalProperties: false },
  locality: 'host',
  effect: 'navigate',
  consent: 'per_call',
  timeoutMs: 5_000,
  handler: async () => {
    const section = document.querySelector('#pricing')
    if (!section) return { status: 'not_found' }
    section.scrollIntoView({ behavior: 'smooth' })
    return { status: 'scroll_requested' }
  },
})
```

The registry is the sole browser execution boundary for chat, voice, forms, slides, page actions, and WebMCP. This handler reports that scrolling was requested; to report the section as visible, wait until the page confirms it is in view.

## 3. Initialize chat

```ts
const client = new ConvincedClient({
  orgSlug: 'acme',
  agentId: 'adpl_public_example',
  tools,
  authorizeToolCall: async ({ tool }) => {
    if (tool.effect === 'read') return true
    return window.confirm(`Allow ${tool.description}?`)
  },
})

await client.initialize()

client.on('state', state => renderConversation(state))
client.on('content', event => renderContent(event.content))

await client.sendMessage('How can you help me?')
```

`agentId` is public configuration. It selects a live Convinced `AgentDeployment`; it is not a secret and does not grant administrative access. Omit it when the organization has one default live widget deployment.

<Note>
  Stop here for chat-only. No microphone is requested and no Live session is created.
</Note>

Before enabling speech, check the [current voice limitation and release status](/guides/widget-sdk/overview#availability-and-validation-status). Completing this quickstart or passing unit tests is not voice rollout approval. Code blocks here are integration fragments: supply your own DOM elements, render functions, organization, deployment and consent UI.

## 4. Add optional voice

```ts
const live = client.createLiveController()

live.on('state', state => renderVoiceState(state))

talkButton.addEventListener('click', () => {
  void live.start().catch(error => showVoiceError(error))
})

endVoiceButton.addEventListener('click', () => {
  void live.end().catch(error => showVoiceError(error))
})
```

Call `start()` only after a visitor action. Show the pending state and any connection error. `endVoiceButton` ends the voice session; a spoken “stop talking” should only interrupt speech, not end the underlying task. The SDK asks the Convinced backend to create a short-lived `gpt-live-1` WebRTC session. The browser never receives an OpenAI API key. Live answers greetings and conversational clarifications directly. It delegates grounded organization, page, slide, and tool requests to `client`'s `gpt-6-luna` conversation. Completed Live-native user/assistant pairs join `client.state.messages` and provide context for both typed and delegated requests.

Continue using `client.sendMessage()` for typed input while voice is active. A new typed request supersedes an unfinished delegated voice turn, then its answer joins the same conversation and can be spoken through Live. `live.end()` stops audio without ending chat.

## 5. End the conversation

```ts
await live?.end()
await client.endSession()
client.destroy()
```

Use an explicit close or completed-conversation action that can await the request. Do not depend on `beforeunload` for durable session completion.

## Optional: mount the managed renderer

Skip this section when your application renders the conversation itself.

```ts
import { mountConvincedWidget } from '@convinced/widget-sdk'

const widget = mountConvincedWidget({
  client,
  voice: live,
  preset: 'managed-v2',
  placement: 'floating',
})
```

The managed renderer uses the same client, Live controller, messages, media, and registry. A headless integration remains the right choice when the website must own exact layout, theme, slide behavior, or form behavior.
