Create one `ClientToolRegistry` before the client. Typed requests and delegated spoken requests that need browser actions use this registry.

```ts
const tools = new ClientToolRegistry()

tools.register({
  version: 1,
  name: 'host_get_page_context',
  description: 'Read the current public page title and route.',
  inputSchema: { type: 'object', properties: {}, additionalProperties: false },
  locality: 'host',
  effect: 'read',
  consent: 'none',
  timeoutMs: 2_000,
  handler: async () => ({
    title: document.title,
    url: location.origin + location.pathname,
  }),
})
```

Tool names should be stable, namespaced, and specific. Keep schemas shallow, reject unknown properties, bound results, and avoid raw HTML or form values.

## Authorization

```ts
const client = new ConvincedClient({
  orgSlug,
  agentId,
  tools,
  authorizeToolCall: ({ tool }) => {
    if (tool.effect === 'read') return true
    return showConsentDialog(tool.description)
  },
})
```

`none` is appropriate only for harmless public reads. Use `session` for a remembered approval within the current session and `per_call` for consequential or sensitive work.

## Signed pause, execute, resume

`gpt-6-luna` never calls browser JavaScript directly. Convinced pauses the turn and returns an opaque, signed, short-lived capability with the pending calls. The SDK does not verify the server signature in the browser. It checks each call against the local registry, schema, bounds, expiry hint, and host authorization, executes the registered `handler`, then returns the result with the opaque capability.

The backend verifies the capability's signature and its organization, session, turn, call IDs, names, arguments, expiry, and call count before resuming `gpt-6-luna`. The browser cannot mint another call, change its arguments, or reuse the continuation for another turn. Spoken requests that need tools delegate to `gpt-6-luna` and use this same path. Live-native greetings and conversational clarifications do not require a tool turn.

## MCP adapters

`createMcpTools()` adapts an application-managed MCP client into registry entries. Discovery is deny-by-default. Keep MCP authentication and network credentials outside the public bundle.

Use [WebMCP](/guides/widget-sdk/webmcp) for tools exposed by the current webpage. WebMCP annotations are hints, not authorization.
