Import from `@convinced/widget-sdk`. The installed TypeScript declarations are the exact signature reference.

## `ConvincedClient`

```ts
import { ConvincedClient } from '@convinced/widget-sdk'

const client = new ConvincedClient({
  orgSlug: 'acme',
  agentId: 'adpl_public_example',
})
```

`agentId` is a public Convinced `AgentDeployment` ID. It is optional when the organization has one default live widget deployment. Pass the optional `tools` registry and `authorizeToolCall` callback when the host exposes browser actions; see the [quickstart](/guides/widget-sdk/quickstart).

In the 0.1.9 candidate, `chatStreamIdleTimeoutMs?: number` bounds the pause between response-body chunks. Its default is **35,000 milliseconds**; supplied values must be positive and finite. It is an idle limit, not an end-to-end response target. Handle a stalled-stream error with a visible retry or typed fallback. Signed tool continuation expiry also covers response-body consumption.

| Work | API |
| --- | --- |
| Start | `initialize()`, `state` |
| Text | `sendMessage()`, `cancelActiveTurn()` |
| Voice | `createLiveController()` |
| WebMCP publishing | `publishToolsToWebMcp()` |
| Identity | `captureIdentity()`, `identify()`, `setIdentity()` |
| Context | `updatePage()`, `updateSessionContext()`, `track()` |
| Lifecycle | `renewSession()`, `endSession()`, `destroy()` |
| Events | `on()`, `once()`, `off()` |

`sendMessage()` is always the typed-input API. When Live is connected, a short verified briefing is sent to Live for speech; the full result stays in the client. Submitting typed input during an unfinished delegated voice turn stops that turn before later browser actions. See [Optional Live voice](/guides/widget-sdk/voice).

## Page observation and screen inspection

SDK 0.1.8 adds `ConvincedClientOptions.pageSnapshot?: { enabled?: boolean; excludeSelectors?: string[] }`, `capturePageSnapshot()`, `PageSnapshot`, `PageSnapshotOptions`, `pageSnapshotLiveContext()` and `createPageFocusTool()`. Automatic capture uses the public main landmark and requires the matching backend.

`client.describeScreen(imageDataUrl, { signal? })` returns `{ observation }` for one approved frame. It does not open a browser capture picker; the host must obtain visitor approval and capture the frame after a user gesture. The backend validates the session and image and returns a bounded textual observation. This remains an experimental path. These APIs are absent from published 0.1.7. See [page-aware guides](/guides/widget-sdk/page-aware-guides#automatic-page-observations) and [availability](/guides/widget-sdk/overview#availability-and-validation-status).

## `ConvincedLiveController`

Create it from the initialized client:

```ts
const live = client.createLiveController()
```

| Work | API |
| --- | --- |
| Connect | `start({ context?, startMuted? })` |
| Microphone | `setMuted(boolean)` |
| Page observation | `sendContextualUpdate(text, contextId?)` |
| Disconnect audio | `end()` |
| Events | `on()`, `subscribe()` |

`end()` closes the Live transport and leaves the client ready for chat. `client.endSession()` ends the canonical conversation.

SDK 0.1.9 retains the existing client, Live controller, and tool-registration methods. It adds the optional stream-idle setting above. Initialization reuses the selected session configuration; an explicit `client.getConfig()` still requests fresh configuration. See [voice delegation](/guides/widget-sdk/voice#delegation-and-tools).

`subscribe(listener)` immediately receives the current `ConvincedLiveState` and returns an unsubscribe function. `on(event, listener)` returns an unsubscribe function for a named event. `ConvincedLiveController` does not expose `once()` or `off()`.

## `ClientToolRegistry`

| Work | API |
| --- | --- |
| Add | `register()`, `registerMany()` |
| Remove | `unregister()`, `clear()` |
| Inspect | `has()`, `get()`, `definitions()` |

Pass the same registry to `ConvincedClient`. Its Live controller automatically uses that registry for client-delegated turns.

Adapters include `createDomTools()`, `registerDomTools()`, `createMcpTools()`, and `createWebMcpBridge()`. The client offers `publishToolsToWebMcp()` for normal WebMCP publishing; `publishRegistryToWebMcp()` is the lower-level API.

Registered tools use `handler`, not `execute`:

```ts
tools.register({
  version: 1,
  name: 'host_open_pricing',
  description: 'Open the pricing section.',
  inputSchema: { type: 'object', properties: {}, additionalProperties: false },
  locality: 'host',
  effect: 'navigate',
  consent: 'per_call',
  timeoutMs: 5_000,
  handler: async () => {
    const section = document.querySelector('#pricing')
    if (!section) return { status: 'not_found' }
    section.scrollIntoView({ behavior: 'smooth' })
    return { status: 'scroll_requested' }
  },
})
```

## Optional managed renderer

`mountConvincedWidget({ client, voice: live, ... })` adds the package's optional managed UI. Its `preset`, `placement`, `theme`, identity policy, and lifecycle methods are presentation conveniences. They do not change the headless conversation contract.

## `ConvincedAgentAdmin`

```ts
const admin = new ConvincedAgentAdmin({ orgSlug, agentId, apiBase })
```

Use `getPrompt()` and `updatePrompt()` only from an authenticated same-origin Convinced admin application or an approved same-origin management proxy that authenticates and authorizes the administrator server-side. They read and update Convinced prompt state only.

## Content helpers

`parseAssistantContent()`, `stripAssistantDirectives()`, `toSafeVideoEmbedUrl()`, and `isSafeHttpUrl()` help custom renderers process typed content. `MessageContentPart` is `text | slide | video`; forms remain host UI driven by application state or tools. Presentation decisions remain with the host UI.
