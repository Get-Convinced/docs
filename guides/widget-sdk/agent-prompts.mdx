Persistent prompt and `firstMessage` changes belong in an authenticated Convinced admin application. They are not visitor-widget operations.

`agentId` is the public Convinced `AgentDeployment` ID used by the SDK. The server uses the authenticated organization membership to authorize a read or write. Provider IDs and provider credentials are absent from this API.

## Create the admin client

```ts
import { ConvincedAgentAdmin } from '@convinced/widget-sdk'

const admin = new ConvincedAgentAdmin({
  orgSlug: 'acme',
  agentId: 'adpl_public_example',
  // Convinced admin origin, or the authenticated management proxy origin.
  apiBase: window.location.origin,
})
```

Use one of these authenticated same-origin arrangements:

- Run the editor on the Convinced application origin with an authenticated organization `ADMIN` session.
- Run it on a customer admin origin whose backend exposes a narrow same-origin management proxy. That proxy must authenticate the customer administrator, authorize the exact organization and `AgentDeployment`, then perform the approved server-to-server Convinced request.

For a proxy, set `apiBase` to the proxy's origin and preserve the documented `/api/org/{orgSlug}/sdk-agents/{agentId}/prompt` path. Do not build an open forwarding proxy or expose its service credential to the browser. `ConvincedAgentAdmin` sends `credentials: 'same-origin'`, rejects redirects, and does not create authentication by itself.

A public widget token, campaign key, provider credential, or visitor session cannot call these endpoints.

## Read and save

```ts
const current = await admin.getPrompt()

const saved = await admin.updatePrompt({
  firstMessage: 'What are you trying to improve today?',
  expectedRevision: current.revision,
})
```

Omitted fields remain unchanged. An empty `firstMessage` lets the visitor speak or type first. Send `systemPrompt` and `firstMessage` together when they must change as one edit.

The endpoint updates the live Convinced prompt version only. The backend owns OpenAI prompts, knowledge, and model configuration; it does not write to a third-party provider dashboard.

Saved changes apply to future sessions that use that live Convinced prompt version. They do not rewrite the transcript or restart an active conversation.

## Handle conflicts

`expectedRevision` prevents a stale editor from silently overwriting a newer save. On `409 prompt_conflict`, reload the current prompt, show the difference, and let the administrator decide what to keep.

See [Get agent prompt](/api-reference/endpoint/get-agent-prompt) and [Update agent prompt](/api-reference/endpoint/update-agent-prompt) for endpoint details.
