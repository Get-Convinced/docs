The managed loader is the fastest path to the complete hosted widget. Convinced owns its rendering, launcher variants, mobile behavior, ElevenLabs voice flow, campaign context, identity gates, chat fallback, slides, videos, and updates.

Use this path when you want the original hosted appearance. Use the [Widget SDK](/guides/widget-sdk/quickstart) when your page must own the renderer or run without an iframe.

## Install the loader

```html
<script
  src="https://app.getconvinced.ai/widget/loader.js"
  data-org="acme"
  async
></script>
```

The loader creates a cross-origin iframe and selects the widget version and launcher configured for the organization.

Campaign attribution comes from the host-page URL by default:

```text
https://www.acme.com/demo?c=northstar-logistics&utm_source=email
```

See [Campaign sessions](/guides/widget-sdk/campaigns) for the exact precedence.

## Loader attributes

| Attribute | Purpose |
| --- | --- |
| `data-org` | Required organization slug |
| `data-token` | Optional public embed token for organizations that require one |
| `data-c` | Explicit campaign target token; overrides URL-derived campaign values |
| `data-pid` | Explicit personalized-link ID |
| `data-host-tools` | Comma-separated opt-in for parent-page tools |
| `data-launcher` | Preview override for a configured launcher style |
| `data-bottom-offset` | Safe CSS length that raises launcher-anchored states |
| `data-test="true"` | Request widget test mode |
| `data-debug="true"` | Request the widget debug surface |
| `async` | Load without blocking the host page |

`data-token` is a public widget embed token. It is not a Campaign API key, a campaign target token, or an ElevenLabs API key.

## Call the public loader API

The parent bridge and experimental [WebMCP adapter](/guides/widget-sdk/webmcp) are separate implementations. This handoff does not add native cross-origin WebMCP discovery to the hosted iframe. [Prompt administration](/guides/widget-sdk/agent-prompts) belongs in an authenticated admin application, not the public loader API.

After the script loads, the loader exposes:

```ts
Convinced.openConvinced()
Convinced.closeConvinced()
Convinced.sendEvent('pricing_plan_opened', { plan: 'enterprise' })
Convinced.setIdentity({
  email: 'priya@acme.com',
  name: 'Priya Rao',
  company: 'Acme Logistics',
  industry: 'Logistics',
  role: 'VP Operations',
})
```

Queue calls before an async loader has finished:

```html
<script>
  window.Convinced = window.Convinced || { _q: [] }
  window.Convinced._q.push([
    'sendEvent',
    'landing_page_loaded',
    { variant: 'enterprise' },
  ])
</script>
<script
  src="https://app.getconvinced.ai/widget/loader.js"
  data-org="acme"
  async
></script>
```

## Enable parent-page tools

The iframe cannot read or modify the parent document by default. Opt in to only the built-ins you need:

```html
<script
  src="https://app.getconvinced.ai/widget/loader.js"
  data-org="acme"
  data-host-tools="page-context,navigate,scroll,highlight"
  async
></script>
```

`data-host-tools="all"` is an alias for those four built-ins. It does not enable custom extensions.

| Opt-in value | Voice client tool | What runs in the parent page |
| --- | --- | --- |
| `page-context` | `host_get_page_context` | Reads URL, title, description, headings, and a compact interactive-element list; omits form values |
| `navigate` | `host_navigate` | Changes a same-origin SPA route |
| `scroll` | `host_scroll_to` | Scrolls one safe selector into view |
| `highlight` | `host_highlight` | Applies and then restores a temporary outline on one safe selector |

These callbacks are available to the managed ElevenLabs client-tool configuration. The exact tool names and schemas must also exist on the ElevenLabs agent.

## Connect navigation to your SPA router

The loader can update `history` and dispatch `popstate`, but framework routers should own their route transition:

```html
<script>
  window.Convinced = window.Convinced || { _q: [] }

  window.Convinced._q.push([
    'setNavigationHandler',
    async (url, { replace }) => {
      if (replace) appRouter.replace(url)
      else appRouter.navigate(url)
    },
  ])
</script>
```

Navigation stays on the parent page's origin. The handler must keep the document alive so the iframe can receive the tool result and the voice agent can continue the same turn.

## Authorize individual requests

Opting into a capability advertises that it may be requested. Read-only page context can run once enabled; navigation, scrolling, highlighting, and custom extensions remain denied until an authorizer approves the individual request. Add the policy before launch:

```html
<script>
  window.Convinced = window.Convinced || { _q: [] }

  window.Convinced._q.push([
    'setHostToolAuthorizer',
    async ({ name, arguments: args }) => {
      if (name === 'host_get_page_context') return true

      return window.confirm(
        `Allow the assistant to use ${name} with ${JSON.stringify(args)}?`,
      )
    },
  ])
</script>
```

The loader validates the message source, expected origin, protocol version, request ID, tool name, argument size, result size, authorization decision, and timeout before returning a correlated response to the iframe. Omitting `setHostToolAuthorizer` therefore leaves every mutating action unavailable even when its name appears in `data-host-tools`.

## Register custom page logic

Register a namespaced function in the parent page:

```html
<script>
  window.Convinced = window.Convinced || { _q: [] }

  window.Convinced._q.push([
    'registerHostTool',
    'host_open_pricing_panel',
    async ({ plan }) => {
      pricingPanel.open(plan)
      return { opened: true, plan }
    },
  ])
</script>
```

The managed ElevenLabs agent reaches registered extensions through `host_extension_call`:

```json
{
  "name": "host_open_pricing_panel",
  "arguments_json": "{\"plan\":\"enterprise\"}"
}
```

`arguments_json` is the canonical ElevenLabs parameter: a JSON object encoded as a string. The managed bridge decodes it before calling the registered parent-page handler.

Custom names must start with `host_` and use lowercase letters, numbers, and underscores. Built-ins cannot be replaced. At most 16 custom extensions may be registered.

<Warning>
  Do not register arbitrary script evaluation, unrestricted DOM access, or a generic fetch proxy. Every extension should represent one bounded product action with a small JSON result.
</Warning>

## Original appearance versus SDK composition

The managed iframe is the source of truth for the current hosted launchers, themes, responsive geometry, and mobile keyboard handling. The SDK's `managed-v2` preset reproduces the functional composition, including managed welcome, engagement, meeting, callout, ticker, position, and theme surfaces, but it does not claim pixel parity with every historical animation and mobile transition.

See [Migration and capability matrix](/guides/widget-sdk/migration) before replacing an existing embed.
