SDK 0.1.7 gives website teams a headless chat and voice client. The website owns its interface, slides, forms, and page actions. Convinced owns the prompt, knowledge, models, session, and provider credentials.

## What changes for an existing SDK integration

- Text and speech share one Convinced session. `gpt-6-luna` handles grounded answers and tool decisions; optional `gpt-live-1` handles full-duplex speech and conversational exchanges through WebRTC. This path uses no ElevenLabs credentials or agent IDs. Voice can stop while chat continues.
- The same `ClientToolRegistry` serves slides, forms, page actions, and WebMCP in chat and voice. `client.publishToolsToWebMcp()` also makes registered actions available to supporting browsers. Luna can continue a request through knowledge and multiple signed browser-tool rounds while Convinced holds the run state server-side.
- Grounded spoken responses can use a short voice briefing while the full answer stays in the chat. Backchannels can leave a task running; a new delegated correction or typed request stops unfinished work before later browser actions.
- Large slide catalogs and page context use bounded Live updates. See [Live payload limits](/guides/widget-sdk/voice#live-payload-limits). Completed Live-native exchanges appear in shared client history and the default session-end transcript; partial fragments and reload/reconnect recovery are not guaranteed.
- The browser uses the public Convinced `agentId` to select a deployment. It receives no OpenAI key. An authenticated Convinced administrator can edit the deployment's saved `systemPrompt` and `firstMessage` for future sessions.

## Enmovil ID for new pages

The **Enmo Buddy SDK** deployment uses:

```ts
const client = new ConvincedClient({
  orgSlug: 'enmovil',
  agentId: 'c4b50540-3323-4037-a2e5-6807d0f1be17',
  tools,
})
```

Use this ID when duplicating the Transformation page's prompt and behavior on another Enmovil page. A different prompt should have its own Convinced deployment and ID. The generic **Test Widget** ID is not the Transformation agent. Add each new website origin to the deployment's allowed domains before testing it.

Pin `@convinced/widget-sdk@0.1.7`, build the host UI, and register only the slide, form, navigation, and WebMCP actions that the page can really perform. Confirm the matching Convinced Live configuration is deployed and begin a fresh Live session. Test chat-only use, voice opt-in, a spoken page-and-slide walkthrough, a backchannel that leaves the task running, a clear mid-task correction that stops stale work, typed input during voice, multiple signed browser-tool rounds, tool denial and timeout, and explicit session completion. Confirm each claimed page or slide action against what is actually visible.
