`ConvincedClient` is the canonical event source for messages, content, tools, identity, and session lifecycle.

```ts
const stopState = client.on('state', state => renderConversation(state))
const stopContent = client.on('content', event => renderContent(event.content))
const stopError = client.on('error', error => showError(error.message))
```

Common client events include:

| Event | Use |
| --- | --- |
| `state` | Render a complete immutable snapshot |
| `message` | Append a completed user or assistant message |
| `message_delta` | Render streaming assistant text |
| `content` | Render structured `text`, `slide`, or `video` parts |
| `client_tool_call` | Show a requested browser action |
| `client_tool_pause` | Diagnose the signed continuation flow |
| `client_tool_result` | Show the observed tool result |
| `identity` | Confirm a durable identity update |
| `error` | Show a recoverable failure |

`paused` means `gpt-6-luna` is waiting for a client tool result. Do not start a second turn until the SDK resumes the first one.

## Live events

```ts
const live = client.createLiveController()

const stopLive = live.on('state', state => renderVoiceState(state))
const stopLiveError = live.on('error', error => showVoiceError(error.message))
```

Live state covers connection, microphone mute, listening, speaking, and errors. Message history still comes from the client. Do not append a separate Live transcript to the conversation.

## Typed input during voice

```ts
await client.sendMessage(input.value)
```

This remains the only typed-input path. If Live is connected, the SDK sends the canonical `gpt-6-luna` answer to Live for speech.

## Teardown

```ts
stopState()
stopContent()
stopError()
stopLive()
stopLiveError()

await live.end()
await client.endSession()
client.destroy()
```

Use an awaited close path. Browser unload events cannot guarantee durable completion.
