This guide is for the partner Knowledge REST API. For page actions in a website, use [WebMCP](/guides/widget-sdk/webmcp). For the browser SDK, start with [SDK overview](/guides/widget-sdk/overview).

## Prerequisites

1. A Convinced organization with knowledge available to query.
2. A partner key from [Settings → API Keys](/guides/getting-started/api-keys).
3. A backend or server-side runtime that stores the key outside the browser.

```bash
export CONVINCED_API_BASE="https://convinced-kb-mcp-production.up.railway.app"
export CONVINCED_API_KEY="<your-partner-api-key>"
```

## Part A — REST endpoint

```http
POST /api/tool
Authorization: Bearer <your-partner-api-key>
Content-Type: application/json
```

| Body field | Meaning |
| --- | --- |
| `tool` | Required REST tool name from the [reference](/guides/mcp/tools) |
| `args` | Tool arguments; send an object, including `{}` for a tool without arguments |
| `scope` | Send `"partner"` for clarity. The authenticated key's stored scope is authoritative; this field is not an access grant |
| `include_slides` | Optional boolean, default false for partner calls; request related slide suggestions |
| `org_slug` | Omit for partner calls. The key selects the organization; a different existing org is rejected with `403` |

### First request

```bash
curl --fail-with-body "$CONVINCED_API_BASE/api/tool" \
  -H "Authorization: Bearer $CONVINCED_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"tool":"search_knowledge","args":{"query":"dispatch planning","limit":5},"scope":"partner"}'
```

### Server-side JavaScript

```ts
const base = process.env.CONVINCED_API_BASE
const apiKey = process.env.CONVINCED_API_KEY
if (!base || !apiKey) throw new Error('Configure the Knowledge API credentials')

async function callKnowledge(tool: string, args: Record<string, unknown>) {
  const response = await fetch(`${base}/api/tool`, {
    method: 'POST',
    headers: {
      Authorization: `Bearer ${apiKey}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({ tool, args, scope: 'partner' }),
    signal: AbortSignal.timeout(30_000),
  })

  const text = await response.text()
  let result: unknown = text
  try { result = JSON.parse(text) } catch { /* Some tools return Markdown. */ }
  if (!response.ok) throw new Error(`Knowledge API ${response.status}: ${text}`)
  if (result && typeof result === 'object' && 'error' in result) {
    throw new Error(String(result.error))
  }
  return result
}

const knowledge = await callKnowledge('search_knowledge', {
  query: 'dispatch planning', limit: 5,
})
```

Do not rely solely on `Content-Type: application/json`: some current handlers return Markdown with that header. A successful request can also return `noData` or `action: "skip"`; preserve those outcomes in your agent's reasoning.

## Part B — MCP SSE protocol

The former partner SSE setup is no longer supported. `/sse` and `/messages` return `410 legacy_transport_retired`. Replacing `/sse` with `/sse/widget` does not create a supported partner connection.

The separate `/mcp/internal` endpoint uses Streamable HTTP and OAuth authorization for approved analyst integrations. A `ck_live_…` partner key is not an OAuth token. Contact Convinced if you need that integration; use `POST /api/tool` for a partner backend today.

## Errors and limits

| Status | Action |
| --- | --- |
| `400` | Check the tool name, JSON, and required arguments |
| `401` | Check the key; it may be missing, disabled, expired, or invalid |
| `403` | The stored key scope cannot call this tool, or `org_slug` conflicts |
| `413` | Reduce the encoded request below 1 MiB |
| `429` | Wait for `retryAfterSeconds` before another REST tool call |
| `500` | The handler failed; capture the request context without logging secrets |

The default key quota is 2,000 requests/hour per service process, shared with Campaign API calls. For production, also bound client-side retries and timeouts. See [API keys](/guides/getting-started/api-keys#rate-limits).
